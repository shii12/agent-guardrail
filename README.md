# 🛡️ Agent-Guardrail

A lightweight, local security guardrail and audit logging layer for autonomous AI Agents (OpenClaw, AutoGPT, Custom Agents).

## 🚀 Features
- **Real-time Command Inspection:** Intercepts system commands generated by AI agents.
- **Risk Classification:**
  - ⛔ **BLOCK (Critical):** Automatically halts destructive commands (`rm -rf`, accessing `.env`, formatting drives).
  - ⚠️ **PROMPT (Medium):** Requires explicit human confirmation (`y/N`) before changing system state.
  - ✅ **ALLOW (Low):** Safely executes read-only or harmless commands.
- **Audit Logging:** Records every execution request with timestamps into `guardrail_audit.log`.
